This is my very first post! I set up this site so I can share thoughts,
updates, and whatever else comes to mind — without needing to touch any
code.

From here on, adding a new post is as simple as filling out a short form on
GitHub and clicking a button. See the `HOW_TO_ADD_A_POST.md` file at the
root of the repository for step-by-step instructions.
